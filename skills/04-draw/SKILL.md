# 生圖（AntiGravity 版）

## 兩條路

| 路線 | 說明 |
|------|------|
| A：內建生圖 | 直接用 generate_image 工具或自然語言產圖，不需 API Key |
| B：API 路線 | 需 `OPENAI_API_KEY` |

## 建議提示格式

```text
生成一張圖片：
用途：
尺寸比例：
主題：
畫面內容：
風格：
色彩：
文字：
限制：
輸出位置：
```

⚠️ 重要中文文字建議後製，專案圖片放在 `assets/` 或 Obsidian 附件資料夾，勿全數 commit 到懶人包 repo。
