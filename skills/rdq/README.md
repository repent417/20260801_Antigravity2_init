# RDQ Method (需求探索四象限法) Skill

> 在執行之前，先把真正的問題找出來。

RDQ Method 是一個結構化的 AI Agent 需求訪談技能，基於知名知識與風險分類模型（Known/Unknown 矩陣）設計。

## 四象限架構
- **Ⅰ 已明說的 (Known Knowns)**：只擷取與確認
- **Ⅱ 想問的 (Known Unknowns)**：只解答與澄清
- **Ⅲ 知道卻沒說的 (Unknown Knowns)**：只提出關鍵追問
- **Ⅳ 沒想到的 (Unknown Unknowns)**：只提供建議菜單供勾選

## 觸發方式
當您說「用 RDQ」、「需求訪談」、「幫我釐清需求」或丟出一個複雜新任務時，Agent 將會載入並進行需求訪談與產出一頁需求規格卡！
